## 🐛 Возможные проблемы и решения

### Проблема 1: Не подключается к серверу

**Симптомы:**
- Ошибка "Не удалось подключиться к серверу"
- Таймаут при проверке `/health`

**Решение:**
```bash
# 1. Проверьте что сервер запущен
sudo systemctl status voicehub

# 2. Проверьте что порт 8080 открыт
sudo ss -tuln | grep 8080

# 3. Проверьте firewall
sudo ufw status

# 4. Проверьте CORS
curl -I http://YOUR_SERVER_IP:8080/health
# Должны быть заголовки Access-Control-Allow-*
```

### Проблема 2: Не работает микрофон

**Симптомы:**
- Нет запроса разрешений
- Другие не слышат вас

**Решение:**
```bash
# 1. Проверьте разрешения браузера
# Настройки сайта → Микрофон → Разрешить

# 2. Проверьте консоль (F12)
# Должны быть логи:
# [WebRTC] Local stream initialized

# 3. Проверьте что микрофон не используется другим приложением

# 4. Перезапустите браузер
```

### Проблема 3: Не работает расшаривание экрана

**Симптомы:**
- Кнопка не работает
- Экран не транслируется

**Решение:**
```bash
# 1. Проверьте что браузер поддерживает getDisplayMedia
# Откройте консоль (F12) и выполните:
navigator.mediaDevices.getDisplayMedia
# Должна вернуть функцию

# 2. Проверьте разрешения
# Настройки сайта → Экран → Разрешить

# 3. Проверьте консоль (F12)
# Должны быть логи:
# [WebRTC] Screen share started
```

### Проблема 4: WebRTC не соединяется

**Симптомы:**
- Нет удаленных видео потоков
- Не слышно других участников

**Решение:**
```bash
# 1. Проверьте STUN серверы
# В webrtc.ts должны быть:
# stun:stun.l.google.com:19302
# stun:stun1.l.google.com:19302

# 2. Проверьте firewall
# Порты UDP 10000-65535 должны быть открыты

# 3. Проверьте NAT
# Если за NAT, нужен TURN сервер

# 4. Проверьте консоль (F12)
# Должны быть логи:
# [WebRTC] Connection state with <user-id>: connected
```

## 📊 Метрики производительности

- **Время загрузки страницы:** < 2 секунды
