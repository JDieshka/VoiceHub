## ⚠️ ВАЖНО: Ограничения

**Без HTTPS микрофон НЕ работает в браузере!**

### Решения:

1. **Desktop приложение (РЕКОМЕНДУЕТСЯ)** ✅
   ```bash
   # Соберите Desktop приложение
   cargo install tauri-cli
   cargo tauri build
   
   # Раздайте пользователям .exe/.dmg/.AppImage
   ```

2. **Получить бесплатный домен**
   - DuckDNS.org → бесплатный поддомен
   - Настроить HTTPS через Let's Encrypt

3. **Только текстовый чат**
   - Веб-версия работает для чата
   - Голосовые каналы не работают
