# 🎯 Упрощенный ввод URL сервера

## Что изменилось

Теперь для подключения к серверу **не нужно** вводить полный URL с протоколом и портом.

## Как работает

### Автоматическая нормализация URL

Приложение автоматически добавляет протокол и порт в зависимости от типа ввода:

| Ввод пользователя | Результат |
|-------------------|-----------|
| `192.168.1.100` | `http://192.168.1.100:8080` |
| `voicehub.com` | `https://voicehub.com:8080` |
| `localhost` | `http://localhost:8080` |
| `server:9000` | `http://server:9000` |
| `http://custom:3000` | `http://custom:3000` (без изменений) |
| `https://secure.com` | `https://secure.com` (без изменений) |

### Правила нормализации

1. **IP адрес без порта** → добавляется `http://` и `:8080`
   - `192.168.1.100` → `http://192.168.1.100:8080`
   - `10.0.0.1` → `http://10.0.0.1:8080`

2. **Домен без порта** → добавляется `https://` и `:8080`
   - `voicehub.com` → `https://voicehub.com:8080`
   - `my-server.example.org` → `https://my-server.example.org:8080`

3. **IP или домен с портом** → добавляется только протокол
   - `192.168.1.100:9000` → `http://192.168.1.100:9000`
   - `voicehub.com:3000` → `https://voicehub.com:3000`

4. **Полный URL** → используется как есть
   - `http://server:8080` → `http://server:8080`
   - `https://secure.com` → `https://secure.com`

5. **localhost** → добавляется `http://` и `:8080`
   - `localhost` → `http://localhost:8080`

## Логика определения типа ввода

### IP адрес
Регулярное выражение: `^(\d{1,3}\.){3}\d{1,3}$`

Примеры:
- ✅ `192.168.1.100`
- ✅ `10.0.0.1`
- ✅ `127.0.0.1`
- ❌ `192.168.1` (неполный)
- ❌ `192.168.1.100.50` (слишком много)

### Домен
Регулярное выражение: `^[a-zA-Z0-9][a-zA-Z0-9-]*[a-zA-Z0-9]*(\.[a-zA-Z]{2,})+$`

Примеры:
- ✅ `voicehub.com`
- ✅ `my-server.example.org`
- ✅ `sub.domain.co.uk`
- ❌ `localhost` (не считается доменом)
- ❌ `server` (нет точки)

### localhost
Специальный случай - всегда обрабатывается как `http://localhost:8080`

## Технические детали

### Функция нормализации

```typescript
const normalizeUrl = (input: string): string => {
  let url = input.trim();
  
  // Убираем trailing slash
  url = url.replace(/\/$/, '');
  
  // Если уже есть протокол - возвращаем как есть
  if (url.startsWith('http://') || url.startsWith('https://')) {
    return url;
  }
  
  // Определяем тип ввода
  const isIPAddress = /^(\d{1,3}\.){3}\d{1,3}$/.test(url);
  const isIPWithPort = /^(\d{1,3}\.){3}\d{1,3}:\d+$/.test(url);
  const isDomain = /^[a-zA-Z0-9][a-zA-Z0-9-]*[a-zA-Z0-9]*(\.[a-zA-Z]{2,})+$/.test(url);
  const isDomainWithPort = /^[a-zA-Z0-9][a-zA-Z0-9-]*[a-zA-Z0-9]*(\.[a-zA-Z]{2,})+:\d+$/.test(url);
  
  // Если это IP или домен без порта - добавляем порт 8080
  if (isIPAddress || isDomain) {
    url = url + ':8080';
  }
  
  // Добавляем протокол
  // Для доменов используем https, для IP - http
  if (isDomain || isDomainWithPort) {
    url = 'https://' + url;
  } else {
    url = 'http://' + url;
  }
  
  return url;
};
```
