## 🚀 Как использовать

### Для пользователей

1. **Откройте приложение**
2. **Введите URL сервера** (получите у администратора)
   - Пример: `http://your-server:8080`
   - Пример: `https://voicehub.example.com`
3. **Нажмите "ПОДКЛЮЧИТЬСЯ"**
4. **Зарегистрируйтесь**
5. **Начните общаться!**

### Для администраторов

#### Вариант 1: Автоматическая установка

```bash
# На вашем сервере
git clone https://github.com/your-username/voicehub.git
cd voicehub

# Запустите установку
chmod +x install.sh
./install.sh

# Готово! Сервер запущен на http://your-server-ip:8080
```

#### Вариант 2: Скрипт деплоя

```bash
# На вашей локальной машине
./deploy.sh your-server-ip

# Скрипт автоматически:
# - Подключится к серверу
# - Скопирует файлы
# - Установит зависимости
# - Соберет проект
# - Запустит сервер
```

#### Вариант 3: Docker

```bash
# На вашем сервере
git clone https://github.com/your-username/voicehub.git
cd voicehub
docker-compose up -d

# Готово! Сервер запущен на http://your-server-ip:8080
```

## 🎯 Примеры использования

### Пример 1: Локальная разработка

```bash
# Запустите сервер
cd server
go run main.go

# Запустите фронтенд
npm run dev

# Откройте http://localhost:5173
# Введите: http://localhost:8080
```

### Пример 2: VPS сервер

```bash
# На сервере 45.67.89.123
./install.sh

# Пользователи подключаются:
# http://45.67.89.123:8080
```

### Пример 3: С доменом

```bash
# На сервере с доменом voicehub.example.com
./install.sh

# Настройте Nginx с HTTPS
# Пользователи подключаются:
# https://voicehub.example.com
```

### Пример 4: Несколько серверов

```bash
# Сервер 1: http://server1.com:8080
# Сервер 2: http://server2.com:8080
# Сервер 3: http://localhost:8080

# Пользователь может подключиться к любому серверу
# и переключаться между ними через профиль
```
