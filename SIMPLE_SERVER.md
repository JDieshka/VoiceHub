# Упрощенная версия VoiceHub Server

## Проблема

Оригинальная версия сервера использует **Pion WebRTC v4**, который требует **Go 1.24+**.
На сервере установлен **Go 1.21.5**, поэтому компиляция не работает.

## Решение

Создана упрощенная версия сервера (`main-simple.go`) **без SFU функциональности**:

### Что убрано:
- ❌ Pion WebRTC зависимости
- ❌ SFU сервер (Selective Forwarding Unit)
- ❌ Групповые звонки через сервер

### Что осталось:
- ✅ WebSocket signaling для P2P соединений
- ✅ Аутентификация (JWT)
- ✅ Регистрация/логин пользователей
- ✅ Создание серверов и каналов
- ✅ Текстовые чаты
- ✅ Голосовые чаты (P2P режим)
- ✅ PostgreSQL база данных

## Режимы работы

### P2P (работает ✅)
- Прямое соединение между клиентами
- Подходит для малых групп (2-5 человек)
- Не требует SFU сервера
- Минимальная задержка

### SFU (не работает ❌)
- Требует Go 1.24+ и Pion WebRTC
- Для больших групп (5+ человек)
- В упрощенной версии отключен

## Установка

### 1. Используйте упрощенный скрипт:

```bash
chmod +x install-simple.sh
sudo ./install-simple.sh
```

### 2. Или вручную:

```bash
cd server

# Создаем backup оригинального main.go
cp main.go main.go.backup

# Используем упрощенную версию
cp main-simple.go main.go

# Загрузка зависимостей
go mod tidy

# Компиляция
go build -o voicehub-server main.go

# Восстанавливаем оригинал
mv main.go.backup main.go

# Запуск
./voicehub-server
```

## Проверка работы

```bash
# Проверка статуса
systemctl status voicehub

# Проверка API
curl http://localhost:8080/health

# Логи
journalctl -u voicehub -f
```

## Ограничения

1. **Только P2P режим** - SFU недоступен
2. **Максимум ~5 участников** в голосовом чате (из-за P2P)
3. **Все участники должны иметь прямой доступ** друг к другу (NAT traversal)

## Когда использовать

✅ **Подходит для:**
- Малых групп (2-5 человек)
- Тестирования
- Локальной сети
- Когда не нужен SFU

❌ **Не подходит для:**
- Больших групп (5+ человек)
- Публичных серверов с NAT
- Когда нужен централизованный медиа сервер

## Обновление до полной версии

Если установите Go 1.24+:

```bash
# Удалите упрощенную версию
sudo ./uninstall.sh

# Установите полную версию
sudo ./install.sh
```

## Файлы

- `main-simple.go` - упрощенная версия сервера
- `install-simple.sh` - скрипт установки упрощенной версии
- `main.go` - полная версия (требует Go 1.24+)
- `install.sh` - скрипт установки полной версии

## Поддержка

Если нужна SFU функциональность:
1. Установите Go 1.24+
2. Используйте `install.sh` вместо `install-simple.sh`

Или подождите обновления Pion WebRTC для поддержки Go 1.21.
