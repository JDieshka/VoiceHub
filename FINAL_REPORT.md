## 📊 Режимы работы

### P2P Mesh (для малых групп)
**Когда использовать:** 2-6 участников

**Преимущества:**
- Минимальная задержка (прямое соединение)
- Нет нагрузки на сервер
- Работает даже если сервер недоступен

**Недостатки:**
- O(n²) соединений
- Высокая нагрузка на upload каждого клиента
- Не масштабируется

### SFU (для больших групп)
**Когда использовать:** 5+ участников

**Преимущества:**
- O(n) соединений
- Низкая нагрузка на клиенты
- Масштабируется до 100+ участников

**Недостатки:**
- Дополнительная задержка (через сервер)
- Нагрузка на сервер
- Требует TURN сервер для NAT traversal

### Автоматический режим
**Как работает:**
- Пытается использовать SFU если доступен
- Если SFU недоступен - переключается на P2P
- Пользователь может вручную выбрать режим

## 🛡️ Безопасность

### Аутентификация
- Пароли хэшируются bcrypt (cost factor 10)
- JWT токены подписываются HMAC-SHA256
- Access token короткоживущий (24 часа)
- Refresh token долгоживущий (7 дней)

### Транспорт
- HTTPS обязательный для продакшна
- WSS для WebSocket соединений
- TLS 1.2+ минимальная версия

### CORS
- Настроен на конкретные домены
- Запрещены произвольные origins
