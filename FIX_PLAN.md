## Проблема 4: Отсутствует голосовая связь ⚠️ КРИТИЧНО

**Причина:** В Tauri WebView `navigator.mediaDevices` может быть недоступен.

**Логи:**
```
[Audio] mediaDevices API not available - creating silent fallback stream
[Audio] Fallback silent stream created
```

**Решение:**

### Вариант A: Использовать Tauri Plugin (рекомендуется)

Установить плагин `@tauri-apps/api` и использовать нативный API для работы с микрофоном.

**Шаги:**
1. Установить плагин: `npm install @tauri-apps/api`
2. Использовать `invoke` для вызова Rust команд
3. Создать Rust команду для захвата аудио

### Вариант B: Исправить CSP и разрешения

1. ✅ Уже добавлено разрешение `microphone: true` в `tauri.conf.json`
2. Проверить CSP
3. Добавить правильную обработку ошибок

### Вариант C: Использовать альтернативный метод

Если `navigator.mediaDevices` недоступен, использовать:
- Системные настройки звука
- Внешние приложения для захвата аудио
- Rust backend для работы с аудио устройствами
