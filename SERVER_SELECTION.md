# 🌐 Универсальное приложение с выбором сервера

## ✅ Реализовано!

Теперь приложение работает как Discord - **один клиент для всех серверов**. Пользователь сам выбирает к какому серверу подключиться.

---

## 🎯 Как это работает

### Поток пользователя:

1. **Запуск приложения** → Страница выбора сервера
2. **Ввод URL сервера** → Проверка доступности
3. **Авторизация/Регистрация** → На выбранном сервере
4. **Использование приложения** → Подключено к серверу
5. **Смена сервера** → Через профиль → Возврат к шагу 1

---

## 📱 Интерфейс

### 1. Страница выбора сервера

```
┌─────────────────────────────────┐
│            MIN                  │
│                                 │
│  Введите адрес сервера для      │
│  подключения                    │
│                                 │
│  адрес сервера                  │
│  ┌───────────────────────────┐ │
│  │ http://your-server:8080   │ │
│  └───────────────────────────┘ │
│                                 │
│  [ПОДКЛЮЧИТЬСЯ]                 │
│                                 │
│  Примеры:                       │
│  • http://localhost:8080        │
│  • http://your-server:8080      │
│  • https://voicehub.example.com │
└─────────────────────────────────┘
```

### 2. Проверка сервера

При нажатии "ПОДКЛЮЧИТЬСЯ":
- ✅ Проверяется формат URL
- ✅ Отправляется запрос на `/health`
- ✅ Проверяется ответ сервера
- ✅ Если всё ОК → переход к авторизации
- ❌ Если ошибка → показывается сообщение

### 3. Страница авторизации

После успешной проверки сервера:
- Ввод логина/пароля
- Регистрация нового пользователя
- Все запросы идут на выбранный сервер

### 4. Профиль с кнопкой "Сменить сервер"

В профиле отображается:
- Текущий сервер
- Кнопка "Сменить сервер" → возврат к шагу 1

## 🔧 Техническая реализация

### Компоненты

**ServerSelectionPage.tsx** - страница выбора сервера
```typescript
interface ServerSelectionPageProps {
  onServerSelect: (serverUrl: string) => void;
  lastServerUrl?: string;
}
```

**Функции:**
- Валидация URL
- Проверка доступности сервера
- Автоматическое добавление `http://`
- Сохранение последнего сервера

### Сервисы

**auth.ts** - динамический URL
```typescript
let API_BASE = '';

export const setServerUrl = (url: string) => {
  API_BASE = url;
};

export const getServerUrl = () => API_BASE;
```

**websocket.ts** - динамический WebSocket URL
```typescript
let WS_URL = '';

export const setWebSocketUrl = (url: string) => {
  WS_URL = url.replace(/^http/, 'ws') + '/ws';
};
```

### App.tsx - логика переключения

```typescript
// Состояния
const [serverUrl, setServerUrlState] = useState<string>(() => {
  return localStorage.getItem('voicehub-server-url') || '';
});

// Если сервер не выбран - показываем страницу выбора
if (!serverUrl) {
  return <ServerSelectionPage onServerSelect={handleServerSelect} />;
}

// Если не авторизован - показываем авторизацию
if (!isAuthenticated) {
  return <AuthPage onLogin={handleLogin} onRegister={handleRegister} />;
}

// Иначе - основное приложение
return <MainApp />;
```

## 💾 Хранение данных

### localStorage

- `voicehub-server-url` - URL выбранного сервера
- `voicehub-access-token` - JWT токен доступа
- `voicehub-refresh-token` - JWT токен обновления
- `voicehub-user` - данные пользователя

### При смене сервера

```typescript
const handleChangeServer = () => {
  // Выход из аккаунта
  authService.logout();
  websocketService.disconnect();
  
  // Очистка URL сервера
  localStorage.removeItem('voicehub-server-url');
  setServerUrlState('');
  setIsAuthenticated(false);
};
```

## 📊 Сравнение с предыдущей версией

### Было:
```typescript
// Захардкоженный URL
const API_BASE = 'http://your-server:8080';
```

**Проблемы:**
- ❌ Нельзя использовать на другом сервере
- ❌ Нужно пересобирать приложение для каждого сервера
- ❌ Неудобно для пользователей

### Стало:
```typescript
// Динамический URL
let API_BASE = '';
export const setServerUrl = (url: string) => {
  API_BASE = url;
};
```

**Преимущества:**
- ✅ Одно приложение для всех серверов
- ✅ Пользователь сам выбирает сервер
- ✅ Не нужно пересобирать приложение

## 🐛 Решение проблем

### Проблема: "Не удалось подключиться к серверу"

**Причины:**
- Сервер не запущен
- Неверный URL
- Firewall блокирует порт
- CORS ошибки

**Решение:**
```bash
# Проверьте что сервер запущен
curl http://your-server:8080/health

# Должно вернуть:
# {"status":"ok","service":"voicehub-server","version":"2.0.0"}
```

### Проблема: "Сервер вернул статус 404"

**Причина:** Неверный путь к API

**Решение:** Убедитесь что сервер запущен на правильном порту

### Проблема: "Таймаут подключения"

**Причина:** Сервер не отвечает за 5 секунд

**Решение:**
- Проверьте что сервер запущен
- Проверьте firewall
- Проверьте сеть

{
  "status": "ok",
  "service": "voicehub-server",
  "version": "2.0.0"

```
POST /api/auth/register
POST /api/auth/login
POST /api/auth/refresh
POST /api/auth/logout
GET /api/auth/me
```

Все запросы идут на выбранный сервер.

### WebSocket

```
WS /ws
```

WebSocket соединение устанавливается с выбранным сервером.
